## Changes

- All units use LAMBS Rush or Hunt instead of move done from separate script loop
- All units spawned as OPFOR in Zeus will have kill points assigned and will give cash on kill
- All units spawned as OPFOR in Zeus will have Hunt/Rush assigned by default.
- Added AI allies to shop. Allies will use LAMBS Camp to send patrols and man defences.
- All vechicles and allies are from PZS: Polish Armed Forces
- All enemies will be from Armed Forces of the Russian Federation.
- Enemy will spawn entire squads of 1-5 soldiers instead of dozens of 1 soldier squads.
- Added Helicopter support with random chance to spawn.
- Reworked special waves. Some modifiers can be used together with others. Fog, Night and arty strike can be used with other specials like Suicide bombers or NATO defectors. It is possible to get more than 1 modifier ex: Drone wave during foggy night or artylery shelling during night when under NATO defectors assault. RNG Based.
- Added artylery strike special wave where area around bulwark will be randomly shelled for entire duration of wave.
- Added 10 wave game limit as option.
- Added heli based ammo drop support power.
- Added back loop to res players with medkits untill i fogure out bug that prevents res.
- Fixed specific location and premade location list spawns for bulwark. (one marker for specific location, all markers starting with bulwarkzone for premade list)
- Nato defectors are hostile to opfor and player faction so its now possible to get 1v1v1 scenario.
